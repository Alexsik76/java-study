# Завдання 1.1 — JDK, JVM, компіляція та запуск

**Етап:** 1. Java Core
**Тема:** 1. Встановлення JDK, будова JVM/JRE/JDK, компіляція та запуск
**Складання:** вручну, без Maven

---

## 1. Мета

Отримати практичне уявлення про повний шлях програми: вихідний код → байт-код → виконання у віртуальній машині. Maven у цьому завданні не використовується навмисно — щоб згодом було зрозуміло, від якої саме ручної роботи він звільняє.

## 2. Середовище

Виконано:

- JDK 21 (LTS), встановлений через SDKMAN;
- перевірено `java -version`, `javac -version`, `echo $JAVA_HOME`.

---

## 3. Програма

Консольний застосунок `SystemProbe` у пакеті `ua.sikorskyi.probe`.

Застосунок виводить у стандартний потік:

1. версію та постачальника середовища виконання;
2. назву й архітектуру операційної системи;
3. кількість доступних процесорів;
4. початковий, максимальний і поточний обсяг пам'яті купи — у мегабайтах;
5. аргументи командного рядка, передані застосунку, або повідомлення про їхню відсутність.

**Напрямок пошуку:** класи `System`, `Runtime`, метод `System.getProperties()`. Конкретні імена властивостей знайдіть у документації, а не підбирайте навмання.

**Порядок реалізації.** Спершу клас, що виводить лише версію Java, і доведіть його до успішного запуску. Далі додавайте показники по одному. Так помилки компіляції залишатимуться локальними та зрозумілими.

## 4. Складання вручну

### 4.1. Структура каталогів

```
system-probe/
├── src/     — вихідні тексти
├── out/     — скомпільовані класи
└── dist/    — готовий артефакт
```

Каталог пакета всередині `src/` має відповідати імені пакета.

### 4.2. Компіляція

```
javac -d out $(find src -name "*.java")
```

### 4.3. Запуск із каталогу класів

```
java -cp out ua.sikorskyi.probe.SystemProbe арг1 арг2
```

Перевірте обидва випадки: з аргументами й без них.

### 4.4. Виконуваний JAR

Створіть файл маніфесту власноруч (не покладайтесь на автоматичну генерацію), зазначте в ньому `Main-Class`. Зберіть архів у `dist/system-probe.jar`.

Перевірка:

```
java -jar dist/system-probe.jar арг1 арг2
```

**Напрямок пошуку:** довідка утиліти `jar`, розділ специфікації про формат файлу маніфесту. Зверніть увагу на вимогу до останнього рядка файлу.

### 4.5. Дослідження байт-коду

```
javap -c -p out/ua/sikorskyi/probe/SystemProbe.class
```

У README наведіть фрагмент виводу та поясніть, що робить інструкція `invokevirtual`.

## 8. Критерії приймання

- програма компілюється й запускається обома способами;
- JAR виконується без зазначення класу в командному рядку;
- відсутність аргументів обробляється без винятку;
- `out/` і `dist/` відсутні в історії репозиторію;
- історія комітів відображає етапи роботи, а не одноразове вивантаження;
- відповіді на запитання сформульовані власними словами.
