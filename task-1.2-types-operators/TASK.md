# Завдання 1.2. Типи даних, змінні, оператори

## 1. Мета

Розрядне представлення цілих чисел, переповнення, приведення типів, семантика операторів. Паралельно — перехід від ручного складання (завдання 1.1) до Maven.

## 2. Розміщення

Репозиторій `github.com/Alexsik76/java-study`, каталог `task-02-types-operators`, гілка `main`.

Maven-проєкт: `groupId` — `ua.sikorskyi`, `artifactId` — `task-02-types-operators`, `maven.compiler.release` — 21, кодування UTF-8. Виконуваний JAR складається `maven-jar-plugin` із зазначенням `Main-Class` у маніфесті. Тести цього разу не потрібні — JUnit починається з етапу 2.

Пакет `ua.sikorskyi.numbers`, головний клас `NumberInspector`.

## 3. Програма

Приймає три аргументи командного рядка: два цілих операнди та символ операції (`+`, `-`, `*`, `/`, `%`).

```
java -jar target/task-02-types-operators-1.0-SNAPSHOT.jar 1024 -7 +
```

Виводить п'ять розділів.

**3.1. Операнди.** Для кожного — десяткове значення, двійкове представлення, доповнене нулями до повної розрядності `int`, і шістнадцяткове.

**3.2. Результат операції в `int`.** Якщо операція переповнює `int`, програма повідомляє про це й додатково показує результат, обчислений у `long`. Для виявлення переповнення використайте методи `Math.*Exact`.

**3.3. Ділення.** Цілочисельне частка й остача поряд із результатом ділення тих самих операндів як дійсних чисел. Розділіть у виводі випадки нульового дільника: для цілих і для дійсних поведінка різна — покажіть обидві.

**3.4. Побітові операції.** `&`, `|`, `^`, `~` над операндами; `<<`, `>>`, `>>>` над першим операндом на один розряд. Виводьте результати у двійковому вигляді.

**3.5. Точність дійсних типів.** Окремий метод: додати `0.1` десять разів у `double`, те саме у `float`, вивести обидві суми з достатньою кількістю знаків і порівняти з `1.0`.

## 4. Вимоги до коду

- Клас `NumberInspector` не має бути суцільним `main`. Метод `main` розбирає аргументи й викликає методи; кожен розділ виводу — окремий метод з осмисленою назвою.
- Вибір операції — `switch`-вираз у стрілковій формі, не ланцюг `if`.
- Розрядність, межі типів і подібні величини беруться з констант стандартної бібліотеки (`Integer.SIZE`, `Integer.MIN_VALUE` тощо), а не записуються числами в коді. Власні константи — `private static final`.
- Хоча б один літерал запишіть у двійковій або шістнадцятковій формі та хоча б один — із розділювачем розрядів (`1_000_000`).
- `var` застосовується лише там, де тип очевидний із правої частини виразу.
- Некоректні аргументи (відсутні, нечислові, невідома операція) обробляються повідомленням і завершенням роботи, а не трасуванням стека.
- Форматування дійсних чисел — `Locale.US`.

## 8. Критерії приймання

- проєкт складається командою `mvn clean package`, JAR запускається без зазначення класу;
- переповнення виявляється й повідомляється, а не залишається непоміченим;
- обидва випадки ділення на нуль показані й пояснені;
- `>>` і `>>>` дають різний результат на від'ємному операнді, що видно з виводу;
- `target/` відсутній в історії репозиторію;
- відповіді сформульовані власними словами.
